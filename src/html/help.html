Look a word up

  1. 01 Alt + double-click a word On any Swedish page.
  2. 02 Select, then Alt + click If you'd rather select first.
  3. 03 Select, click the toolbar icon Opens the popup instead. You can also type a word there.

Export your history

Every lookup is stored, per language. Go to History, tick the rows you want, and choose Export ▾. Pick TSV (Quizlet-ready) and paste the file straight into Quizlet's import box — the default separators already match. Anki .txt and CSV are there too, and Copy to clipboard skips the file altogether. With nothing ticked, you export everything in view.

Settings

Options is where you choose which languages appear in the picker, which one a lookup uses by default, whether the extension follows your system's light or dark appearance, and whether lookups are recorded at all.
